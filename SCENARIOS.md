## T3 — Identity: which hello?

- **World:** `base` · **asked from:** `greet-lib` · **read limit:** 1 file
- **Plain meaning:** The library team asks: which code in other repos uses our hello()? (Four web-app files import the library; one uses hello; web-app also has its own hello.)
- **Question (exact):** This repository is the npm package greet-lib. Which code in the other repositories uses our hello function (src/index.ts)? List every use as repo/file:line.
- **Lesson:** Identity needs the compiler: the syntax graph only knows that 4 files import the package; with one file allowed to open (standing in for scale), it can't tell which uses hello.

**Answer key:**

> Exactly one file uses greet-lib's hello: web-app/src/main.ts — line 1 imports hello from "greet-lib", line 5 calls it inside run().
> Traps: web-app/src/footer.ts, logout.ts and local.ts also import from greet-lib but use only goodbye; web-app/src/local.ts also defines its OWN function hello, never used.
> Scoring: correct = gives web-app/src/main.ts lines 1 and 5 AND states that it is the only use (the other importers do not use hello). partial = gives main.ts but leaves other importers as possible or unverified uses. wrong = lists a trap file as a use, or finds nothing.

**Deterministic checks (`bin/check`):**

- `l2` `graph_callers(hello)` → lacks ['main.ts']
- `l2` `graph_explain(greet-lib)` → contains ['main.ts', 'footer.ts', 'logout.ts', 'local.ts']
- `l3` `scip_references(scip-typescript npm greet-lib 1.0.0 src/`index.ts`/hello().)` → contains ['web-app/src/main.ts:5', 'web-app/src/main.ts:1']; lacks ['local.ts', 'footer.ts', 'logout.ts']
