Core 3x3: one session per cell

Three scenarios, three graphs, and each scenario is answered correctly by exactly one graph. Each one-liner opens a live Claude session (Haiku) with that cell's tools, with the question already sent. The green-bordered cell in each row is the one expected to answer correctly.

How a session works
  1. Paste a one-liner into your WSL terminal. The banner shows the instructions the session is given (CLAUDE.md) and the question.
  2. Claude starts with the question as its first message. Watch which org tools it calls.
  3. Compare its answer with the answer key below. Type /exit to leave; the transcript is saved to results/sessions/.
  4. For a graded PASS/FAIL instead, run bin/verify T3 --configs X-G3 --reps 1 (same scenario/configuration names).
